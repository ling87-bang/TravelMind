# KnowGo 演示说明

启动项目后访问 http://127.0.0.1:3000 。启动与测试命令见 [README](README.md)。

## 推荐演示路径

1. 注册或登录自己的本地账号，新建行程。
2. 选择北京出发、天津和上海两个目的地，安排四天，交通方式选择高铁，日期选择已开售日期。
3. 确认目的地顺序，选择全部交通段并提交，检查已选车次回执。
4. 选择各站住宿。实时酒店数据不可用时使用明确标注的品牌候选。
5. 提交住宿并等待生成行程。生成过程中刷新页面，验证后台继续生成及运行状态恢复。
6. 打开行程清单，检查四天安排和预算，再刷新验证已选卡片与清单入口可恢复。
7. 点击会话右侧“更多”，选择归档，在确认框中核对会话名称后确认。从“已归档”列表恢复会话。

## 自动化验证

后端回归覆盖卡片快照持久化、提交去重、冲突选择、失败重试、断线后继续生成、资源权限、预算和密码校验。PostgreSQL 集成测试为每项创建独立临时 schema，并在结束后清理。

前端回归覆盖流式错误、切换会话、刷新恢复、重复请求标识和归档、恢复。类型检查与生产构建需一起执行。

自动化完整 HTTP 流程使用模型和第三方服务替身。真实模型、12306 和可选外部服务需使用自己的配置验证。未核验的酒店、门票及餐饮金额属于参考或估算。

## 配置与运行状态

实际密钥保存在本地 `.env` 中。首次安装后填写模型密钥，数据库配置由本地配置工具生成。运行日志位于 `.runtime/` 和后端 `logs/`。

地图、天气、航班和实时报价酒店依赖各服务的配置。项目不执行真实订票或支付。
